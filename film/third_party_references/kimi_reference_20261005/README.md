# Kimi reference assets

This directory is the asset boundary for the `world-execute-me-kimi` adaptation.

- `maid-left.webp` is the Kimi full-body reference used by the hakimi web renderer and the stand-in dancer.
- `kimi-study.webp` is the moonlit study background reference.
- `expressions/` contains eight deterministic Kimi expression variants used by the hakimi web chat pages; the runtime names are `cat-*.webp` because the mascot is Hajimi's kitten.
- The runtime uses only the Kimi standing art and the `cat-*.webp` expression variants in this directory.

The renderer keeps the original timing, page batches, TUI cuts, frame rate, and post-processing stages. The character asset boundary, visible Kimi labels, black background, and mascot silhouette are adapted here.
